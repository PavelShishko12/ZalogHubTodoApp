# Список задач

Простое приложение для управления задачами на React, TypeScript и Vite.

## Возможности

- добавление новых задач;
- отметка задачи как выполненной или активной;
- удаление задач;
- фильтрация: все, активные и выполненные;
- сохранение задач в `localStorage`;
- запрет добавления пустых задач.

## Требования

- Node.js 18 или новее;
- npm.

## Установка и запуск

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

После запуска откройте адрес из терминала, обычно `http://localhost:5173`.

## Дополнительные команды

Проверка production-сборки:

```bash
npm run build
```

Проверка кода ESLint:

```bash
npm run lint
```

Предварительный просмотр production-сборки:

```bash
npm run preview
```

## Время выполнения

Примерное время выполнения задания: **40 минут**.
